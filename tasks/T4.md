### reza-phys/conductor (cloned, 2 commits, 0.1.0 2026-10-01, 0.2.0 2026-10-06)
- What: Python hooks plugin; event log (.conductor/events.jsonl) replayed into status.json/html; SubagentStop gate checks report blocks.
- Evidence: 28 tests pass locally (`pytest tests`, 5.9s). Issue #1 (closed, author's own field report): in a real session every gated agent (2 workers, 3 auditors) was blocked forever. The gate read only `last_assistant_message`, agents ended with a `SubagentHandback` tool call, the block went nowhere, and the dashboard showed "running · gate blocked" forever (F1-F3). Also F4: two background workers dispatched in one message got each other's task. F5: Claude Code prompt-suggestion helper loops showed up as "?" agents. F6: init mid-session never activated.
- Lesson: an enforcing gate on agent stop is fragile and fails closed in a way nobody sees; matching agents to tasks by dispatch order is wrong; filter helper loops out of agent lists. Its event-log-to-deterministic-render path is the good part.

### xuanji86/claude-agentpane (cloned, 10 commits, 1.1.4 2026-10-04, 3 stars)
- What: subagent pane on the same 2.1.28x mod API. Tests: hooks/pane.test.tsx, agentpane.test.ts (draw the pane at 40-120 cols on every surface; not run here, they need the engine types).
- Worked (from CHANGELOG + register.tsx): polls `$.agent.list()` once a second because "no agent-status event reaches a mod" (register.tsx:10), with a single-flight flag so a slow list only skips ticks (:452); lists at `agent.spawn` ahead of the poll; status line `2 of 4 agents running` when folded; counts unclaimed model loops (compaction, memory forks) separately; caps drawn tool calls at 40 (the engine refused an oversized pane); clocks on the surface frame clock, not re-renders (1.1.0 cut redraws 5/s).
- Bugs it hit: poll rebuild dropped fields set by events (1.1.3, effort vanished in 1s), so merge, don't replace; desktop app has its own agents view, so stay quiet there (1.1.4).
